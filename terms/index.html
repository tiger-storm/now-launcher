2. Description of the Service

Now Launcher is an Android home-screen launcher. Free features include user-ordered Sections, All Apps and search. Pro adds contextual Suggestions and other features described in the App. Optional features include contacts, calendar, media controls, reminders, timers, weather and sports information. Availability depends on your device, Android version, permissions and any required online service.

Default Search lets you choose Google, Bing, DuckDuckGo or Device default for submitted searches. Google is the default for an unset preference; existing choices are preserved. Suggestions are separately set to On-device by default. Online adds suggestions from your chosen engine only after a separate confirmation explaining that text is sent before submission. You can return to On-device in search settings; changing engines also returns suggestions to On-device. Device default opens submitted searches in your device's search handler, where available. The existing search-result actions continue to open the selected result. Online content can be delayed, incomplete or unavailable. See the Privacy Policy for details.
